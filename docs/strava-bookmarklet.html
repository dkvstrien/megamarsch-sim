📡 Strava → GPX

One-click export with full timestamps. No account access needed.

Drag this button to your bookmarks bar:

Strava → GPX

To use:
  1. Open any of your Strava activities (must be logged in)
  2. Click the Strava → GPX bookmark
  3. GPX file downloads with full position & time data

Then upload the .gpx file to the Megamarsch Sim and replay it alongside the simulated field.

Works by calling Strava's own API from within your authenticated page session. No data sent anywhere. No third-party access.

If it stops working, check for updates.
